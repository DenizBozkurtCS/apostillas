# "Add to Shelf…" on the Book page

Status: ready-for-human
Blocked by: 01

## Acceptance criteria

- The Book page's ⋯ menu gets **Add to Shelf…**, opening a dialog with a checkbox per Shelf (in Bookcase order), ticked for Shelves the Book is already on. Ticking adds the Book at the end of that Shelf; unticking removes it.
- The dialog can make a new Shelf (name only) and puts the Book on it.
- The Book page itself does not list the Book's Shelves.
