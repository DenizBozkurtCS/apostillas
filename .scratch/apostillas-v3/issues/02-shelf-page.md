# A Shelf's page: adding, removing and arranging Books

Status: ready-for-human
Blocked by: 01

## Acceptance criteria

- `/bookcase/<slug>` shows the Shelf's name, its description (only shown here), its Book count, and every Book as a cover tile (same tiles as the Library lists) in the Shelf's order. No sort or filter controls.
- Rename the Shelf and edit its description here. Renaming moves the page to the new address.
- **+ Add books** searches the reader's library by title or author; picking a Book adds it to the end. Books already on the Shelf are marked and can't be added twice.
- Each Book can be removed from the Shelf (the Book itself stays).
- **Arrange** mode: drag covers to reorder; move-earlier/move-later buttons work on phones and from the keyboard. **Done** saves the order.
- An empty Shelf says "No books yet" and offers + Add books.
