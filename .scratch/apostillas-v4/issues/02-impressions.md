## Acceptance criteria

- "Leave an Impression" on the Book page opens a form: date (required, today by default), optional ½–5 rating, optional short review (plain text, up to ~1,000 characters), Reread and Didn't finish tick boxes.
- Saving an Impression with a rating sets the Book's Rating (most recently set wins). Impressions never change Reading Statuses.
- The Book page's tab is **Impressions**: newest first by date (ties: newest saved first), each with date, stars, ↻ Reread / ⊘ Didn't finish icons, and the review; edit and delete in place.
- No start dates anywhere.
