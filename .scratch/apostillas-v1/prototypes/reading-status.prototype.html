Reading Status: does the model feel right?

One Book, in memory. The Reading Status is never set directly. It is worked out from the Book's Reads (ADR-0005): any open Read → Reading; otherwise any Finished Read → Finished; otherwise any Abandoned Read → Abandoned; no Reads → Want to read. A Read is a Reread if an earlier Read was Finished, or you ticked "I've read this before". Quotes and Notes can't be added while the Book is Want to read. Click the actions or step through a scenario and check that what happens matches what you'd expect.
