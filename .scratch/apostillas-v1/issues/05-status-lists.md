# Reading, Want to read, Finished, and Abandoned lists

Status: ready-for-agent
Blocked by: 02

## Acceptance criteria

- Four lists, one per Reading Status, with navigation between them; Reading is the home screen
- Each entry shows cover, title, and author, and links to the Book page
- Want to read: shows date added and "why" if present
- Finished: sorted by most recent finish date; shows rating, and a reread icon when the latest Finished Read is a Reread
- Abandoned: shows the date abandoned
- Empty states link to Add book
